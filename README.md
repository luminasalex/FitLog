### What I Learned

While making this project, I learned how to use **Next.js routing, React components, TypeScript interfaces, props, Tailwind CSS, dynamic data and responsive design**. I also learned how to create reusable UI components and use Tailwind CSS for **responsive layouts, hover effects, cards, buttons and modern UI design**.

### Project Name

**FITLOG**

### Description

FITLOG is a simple fitness and workout website. I made this project to practice **Next.js, React, TypeScript and Tailwind CSS**. In this website, users can see different workouts and their details. They can also add workouts to their plan, save workouts and mark a workout as completed.

### Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- JavaScript

### Features

- Users can see different workouts.
- Users can view workout details.
- Users can add workouts to **My Plan**.
- Users can save their favorite workouts.
- Users can mark workouts as **Done**.
- Workout duration and calories are shown.
